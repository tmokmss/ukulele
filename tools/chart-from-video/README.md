# 練習動画から譜面を起こす

コードが画面に表示されるウクレレ練習動画から、コード進行を読み取るための道具。

```sh
pip install yt-dlp numpy pillow    # 別途 ffmpeg が要る
python extract.py "<YouTube URL>" -o out/
```

`out/tileNN.png` にコード帯がページごとに並ぶので、それを見てコードを書き起こし、
`charts/*.json` として置く。

## なぜこの形か

コードを画面に出すタイプの動画では、進行は説明欄にも字幕にも無い。実測では、

- 説明欄 — yt-dlp なら全文取れるが、この手の動画には進行が書かれていない
- 自動字幕 — 日本語 ASR がコード名を壊すため使えない
- 音声からの自動採譜 — 伴奏入りだと精度が出ない

ので、画面を読むのが一番確実だった。コード帯は表示が変わるまで完全に静止しているため、
フレーム差分でページの切れ目がはっきり出る（変化時 4〜15 に対し静止時は 0.15 以下）。
あとはページごとに 1 枚だけ代表フレームを見ればよい。

コード名を読む部分だけは自動化していない。OCR ではダイアグラムと混ざるうえ、
`G7` と `C7`、`Dm` と `Dm7` の取り違えが致命的になるため。

## charts/*.json

`chords` は `[コード名, 拍数]` の並び。4 拍で 1 小節。歌詞は入れない。

現在: [country-road.json](charts/country-road.json) — 128 小節 / BPM 153 / C Dm Am F G7

## アプリに載せるには

`Settings.prog` は `string[]` で、長さは `bpc`（1 コードあたりの拍数）が全コード共通。
この譜面は 2 小節・1 小節・半小節が混ざるので、そのままでは載らない。
拍数を持てる形に広げるか、均等な進行に丸めるかの判断が要る。
