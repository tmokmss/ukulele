# 楽譜 (コード譜) の書き方

画面の「楽譜」に JSON を貼ると、その曲を頭から通して練習できる。
コードが流れてくるレーンも、クリックのアクセントも、採点もそのまま曲に合わせて動く。

```json
{
  "title": "きらきら星",
  "bpm": 90,
  "beatsPerBar": 4,
  "repeat": 2,
  "bars": [
    "C", "F C", "C", "G7 C",
    "F C", "F C", "F C", "G7 C",
    "C", "F C", "C", "G7 C"
  ]
}
```

## 項目

| 項目 | 既定 | 内容 |
|---|---|---|
| `bars` | 必須 | 小節を並べる。文字列1つが1小節 |
| `title` | 名前のない楽譜 | 曲名。記録にこの名前で残る |
| `bpm` | なし | 読み込んだときテンポに入る (40〜180 に収める)。省略すると、いまのテンポのまま |
| `beatsPerBar` | 4 | 1小節の拍数。クリックのアクセントもこの間隔で鳴る |
| `repeat` | 1 | 通す回数。2 にすると頭から2周して終わる |

## 小節の書き方

- **1小節1コード**: `"C"` — その小節はぜんぶ C
- **小節を割る**: `"G7 C"` — 4拍なら 2拍ずつ。`"C Am F G7"` なら1拍ずつ。
  **等分できない数は書けない** (4拍を3つ、など)。3拍目で変えたいときは次の `.` を使う
- **伸ばす**: `"."` は直前のコードをそのぶん伸ばす
  - `["C", "."]` → C を2小節
  - `["C . . F"]` → 4拍の小節で、C を3拍・F を1拍
  - `["C . Am"]` (3拍子) → C を2拍・Am を1拍
  - `-` と `%` も `.` と同じ意味
- **1行にまとめる**: `"C | F | G7 C"` のように `|` で区切ってもいい。
  `"bars": "C | F | G7 | C"` と、配列にせず文字列1本でも書ける
- 小節だけでいいなら `["C", "F", "G7", "C"]` と、いちばん外も配列にできる

## コード

使えるのは、このアプリが押さえ方と判定テンプレートを持っているものだけ。

```
C  Am  F  G  G7  D  Dsus2  D7  Dm  Em  A  A7  E7  C7  Bb  Am7
```

知らないコードが入っていると、その名前を並べて読み込みを断る。
増やすときは `src/core/chords.ts` の `CHORDS` にフレット番号 (4弦→1弦) を足す。

## 練習中の見え方

- 画面上の表示は「いま何小節目 / 全部で何小節」。`repeat` のぶんも数える
- コードの切れ目 (小節の頭とは限らない) がチェンジの採点対象。
  切れ目で鳴らしたストロークが、タイミングのレーンで大きな点になる
- 最後まで行くと自動で止まり、結果が出る。途中で止めても、そこまでが採点される

## 曲を探すとき

U-フレットや楽器.me のコード譜を、小節ごとに書き写すのがいちばん早い。
歌詞は要らない。コードと小節の区切りだけ拾えばいい。
