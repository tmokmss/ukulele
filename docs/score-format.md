# 楽譜 (コード譜) の書き方

楽譜は **`songs/*.json` でリポジトリ管理する**。アプリはそれを読み込んで、
画面ではタイトルから選ぶだけ。選んだ曲を頭から通して練習でき、コードが流れてくる
レーンも、クリックのアクセントも、採点も曲に合わせて動く。

```
songs/
  kirakira-boshi.json   ← ファイル名が id (設定に残るのはこれ)
  island-strum.json
  waltz.json
```

- 画面に出る名前は JSON の `title`。ファイル名は半角の小文字とハイフンで付ける
- 増やすときは `.claude/skills/ukulele-score/` のスキルに書かせる
- コミット前に `npm run score` で全部が読めることを確かめる
  (壊れたものは一覧から消える。`npm test` でも落ちる)
- 読めなかったときのエラー文は、そのまま Claude に投げ返せば直せる形にしてある

```json
{
  "title": "きらきら星",
  "bpm": 90,
  "beatsPerBar": 4,
  "strum": "D-DU-UDU",
  "sections": [
    { "name": "A", "repeat": 2, "bars": ["C", "F C", "C", "G7 C"] },
    { "name": "B", "bars": ["F C", "F C", "F C", "G7 C"] }
  ]
}
```

## 項目

| 項目 | 既定 | 内容 |
|---|---|---|
| `bars` または `sections` | 必須 | 小節。どちらか一方でいい |
| `title` | 名前のない楽譜 | 曲名。記録にこの名前で残る |
| `bpm` | なし | 読み込んだときテンポに入る (40〜180 に収める)。省略すると、いまのテンポのまま |
| `beatsPerBar` | 4 | 1小節の拍数。クリックのアクセントもこの間隔で鳴る |
| `repeat` | 1 | 曲全体を通す回数 |
| `strum` | なし | ストロークのパターン。セクションごとに上書きできる |

## 小節

- **1小節1コード**: `"C"` — その小節はぜんぶ C
- **小節を割る**: `"G7 C"` — 4拍なら 2拍ずつ。`"C Am F G7"` なら1拍ずつ
- **伸ばす**: `"."` は直前のコードをそのぶん伸ばす (`-` と `%` も同じ)
  - `["C", "."]` → C を2小節
  - `["C . . F"]` → 4拍の小節で、C を3拍・F を1拍
  - `["C . Am"]` (3拍子) → C を2拍・Am を1拍
- **食い込み**: 8分・16分の位置にも置ける。`"C - - - - F - -"` は、C が2.5拍で F が3拍半から入る
- **割り方の制限**: 1小節を割れるのは**16分音符まで**。4拍なら 1/2/4/8/16 個に割れる。
  3個のような中途半端な数は書けないので、`.` で位置を作る
- **1行にまとめる**: `"C | F | G7 C"` のように `|` で区切ってもいい。
  `"bars": "C | F | G7 | C"` と、配列にせず文字列1本でも書ける
- 小節だけでいいなら `["C", "F", "G7", "C"]` と、いちばん外も配列にできる

## セクション

長い曲は `sections` で区切ると、同じ小節を何度も書かずに済む。

```json
"sections": [
  { "name": "Aメロ", "repeat": 2, "bars": ["C", "Am", "F", "G7"] },
  { "name": "サビ", "strum": "DDDD", "bars": ["F", "G7", "C", "C"] }
]
```

- `name` は画面のエラー文に出るだけ。省略できる
- `repeat` はそのセクションだけの繰り返し (1〜16)
- `strum` を書くと、そのセクションだけパターンが変わる

## ストローク

`strum` は **文字数がその小節の分割数**になる。8文字なら8分、16文字なら16分。

| 文字 | 意味 |
|---|---|
| `D` | ダウン (`↓` でも可) |
| `U` | アップ (`↑` でも可) |
| `x` | ミュート (チャッ) |
| `-` | 鳴らさない (`.` `_` も可) |

```
"D-DU-UDU"   よくある8ビート (アイランドストローク)
"DDDD"       4分で刻むだけ
"D-DU-UD-"
```

読みやすいように空白を入れてもいい (`"D-DU -UDU"`)。
文字数は小節を割り切れる数にすること (4拍なら 1/2/4/8/16 文字)。

## 何が採点されるか

| 書いたもの | 採点 |
|---|---|
| `strum` あり | **1打ごと**のタイミング、鳴らし漏れ、余分なストローク、強さの粒 |
| `strum` なし | コードの切れ目のタイミングだけ (従来どおり) |
| コードが0.5秒以上 | 上に加えて、コードが合っているか・弱い弦 |
| コードが0.5秒未満 | コード判定はしない (クロマ用の FFT は窓が約340msあり、混ざってしまうため) |

リズムだけを採点するときは、重い FFT ごと止める。
画面の「いま聞こえている音」と弦ごとのメーターも、そのあいだは出ない。

16分を採点できるのは**約135BPMまで**。それ以上は、1回のストロークを2回と数えないための
不応期 (110ms) に引っかかる。

## コード

使えるのは、このアプリが押さえ方と判定テンプレートを持っているものだけ。

```
C  Am  F  G  G7  D  Dsus2  D7  Dm  Em  A  A7  E7  C7  Bb  Am7
```

知らないコードが入っていると、その名前を並べて読み込みを断る。
足りないときは移調するか、近いコードに寄せる。
増やすときは `src/core/chords.ts` の `CHORDS` にフレット番号 (4弦→1弦) を足す。

## 追加のしかた

1. `songs/<英数字のファイル名>.json` に書く
2. `npm run score -- songs/<ファイル名>.json` で確かめる
3. `npm run dev` の画面で「楽譜」の一覧に出るので、選んで弾いてみる
4. コミットして push すると、GitHub Pages のほうにも出る

## 練習中の見え方

- 画面上の表示は「いま何小節目 / 全部で何小節」。`repeat` のぶんも数える
- レーンの下に、`strum` の矢印が流れてくる
- 打点で鳴らしたストロークは、タイミングのレーンに点で出る。
  どこにも寄らなかったストロークは中抜きの点になる
- 最後まで行くと自動で止まり、結果が出る。途中で止めても、そこまでが採点される
